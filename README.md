# Antigravity Voice Assistant

Локальный голосовой ассистент и командный центр для Windows 11 с нативной поддержкой аппаратной клавиши **Copilot** (`Shift + Win + F23`) и видеокарты **NVIDIA GeForce RTX 5050**.

---

## Возможности

1. **Аппаратная клавиша Copilot (`Shift + Win + F23`):**
   - **Одиночный клик (Tap-to-Talk):**
     - Если ассистент активен: звучит мягкий сигнал активации («бип»), приглушается фоновый звук системы (Audio Ducking), внизу экрана появляется полупрозрачная «пилюля»-индикатор с текстом речи в реальном времени.
     - Если ассистент остановлен: появляется диалоговое окно *«Ассистент остановлен. Запустить его сейчас? [Да / Нет]»*.
   - **Удержание (Hold от 0.4 сек):**
     - По центру активного монитора всплывает строка **Spotlight** с историей запросов (`Вверх`/`Вниз`), подсказками частых команд и мгновенным фокусом ввода.
2. **Глубокая интеграция с Antigravity:**
   - **Antigravity 2.0 (GUI):** Активация окна, создание нового чата (`Ctrl+N`), вставка голосового промпта в поле ввода и авто-отправка по `Enter`.
   - **Antigravity CLI:** Открытие новой интерактивной вкладки в Windows Terminal с утилитой `agy` (`wt.exe powershell -NoExit agy -p "..."`).
3. **Экономный VRAM-контур:**
   - В активном режиме занимает всего **~1.7 ГБ VRAM** (Faster-Whisper Small на CUDA + Qwen2.5-1.5B Q4).
   - Кнопка **«Остановить ассистента»** в GUI или трее **полностью выгружает модели из VRAM до 0 МБ**, освобождая память под тяжелые игры.
4. **Настройка режима запуска по умолчанию:**
   - Переключатель в настройках GUI:
     - *«Только кнопка Copilot»* (100% приватность, 0% нагрузки на CPU).
     - *«Кнопка Copilot + Wake Word Джарвис»* (Hands-free вызов голосом).
5. **Системные функции:**
   - Точная регулировка громкости в % (`pycaw`), медиаклавиши (пауза, следующий трек), запуск любых приложений и сайтов.
   - Защита от случайных опасных действий (выключение/перезагрузка ПК требуют голосового подтверждения).
   - Автозапуск с Windows (опционально в свернутом виде в трей).
   - Диалог при нажатии на крестик с опцией «Запомнить мой выбор».

---

## Запуск приложения

- **С рабочего стола:** Дважды кликните по созданному ярлыку **`Antigravity Voice.lnk`** (запуск происходит тихо без черного окна консоли через `pythonw.exe`).
- **Из терминала:**
  ```powershell
  Set-Location "C:\Users\denis\Documents\antigravity\localAgent"
  .\.venv\Scripts\python.exe main.py
  ```

## Структура проекта

```text
localAgent/
├── config/
│   ├── settings.json       # Конфигурация приложения
│   └── commands.json       # Словарь соответствия команд и программ
├── core/
│   ├── audio_listener.py   # Захват звука, VAD и VU-метр
│   ├── audio_ducking.py    # Приглушение системного звука Windows
│   ├── speech_to_text.py   # Faster-Whisper Small (CUDA) с выгрузкой VRAM
│   ├── decision_engine.py  # Fast-Path и семантический роутер
│   ├── executor.py         # Win32 API, Antigravity CLI/GUI, громкость, медиа
│   └── keyboard_hook.py    # Низкоуровневый перехватчик клавиши Copilot
├── gui/
│   ├── main_window.py      # Главное окно Fluent Dark
│   ├── floating_pill.py    # Плавающий оверлей-индикатор статуса
│   ├── spotlight_bar.py    # Плавающая строка ввода команд Spotlight
│   ├── close_dialog.py     # Модальное окно подтверждения закрытия
│   ├── tray_manager.py     # Управление системным треем Windows
│   └── styles.py           # Темная цветовая схема и QSS
├── sounds/                 # Звуковые сигналы (активация, успех, ошибка)
├── create_shortcut.py      # Скрипт создания ярлыка на Desktop
├── main.py                 # Главная точка входа
└── pyproject.toml          # Зависимости uv
```
