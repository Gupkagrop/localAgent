# Antigravity Voice & Vision Assistant (Jarvis)

Автономный локальный голосовой ассистент и **Vision Computer-Use агент** для Windows 11 с нативной поддержкой аппаратной клавиши **Copilot** (`Shift + Win + F23`) и аппаратным ускорением на **NVIDIA GeForce RTX 5050 Laptop GPU (8 ГБ VRAM)**.

---

## Ключевые возможности

1. **Мультимодальный Computer-Use Агент (Зрение и Руки):**
   - **Автономная навигация в любом интерфейсе:** Ассистенту не нужны захардкоженные скрипты под каждый сайт или приложение. Модель видит текущий экран пользователя через мгновенный захват GDI BitBlt (4 мс), находит нужные поля/кнопки и выполняет действия мышью и клавиатурой.
   - **Специализированная VLM (Jedi-3B-1080p / Qwen2.5-VL-3B):** Запускается в 4-битном режиме (BitsAndBytes NF4), потребляя всего **~3.2–3.5 ГБ VRAM** с кэшем. Обладает субпиксельной точностью клика в мелкие десктопные элементы и полной нативной поддержкой русского языка (OCR и промпты).
   - **Цикл восприятия и проверки (Sense-Act-Verify):** Скриншот → Определение координат `[0..1000]` → Win32 Input → Контрольный скриншот → Завершение задачи.

2. **Двухуровневый гибридный маршрутизатор (Fast Path + Vision Loop):**
   - **Fast Path (~5 мс):** Системные команды (регулировка громкости в %, приглушение звука, сворачивание всех окон `Win+D`, блокировка ПК, быстрый запуск программ) отрабатывают мгновенно через Win32 API без нагрузки на нейросеть.
   - **Vision Path:** Сложные визуальные задачи (*«Найди видео Мармука на YouTube»*, *«Напиши сообщение в Telegram»*, *«В Antigravity запусти тесты»*) автономно решает Vision-агент.

3. **Голосовой контур (Faster-Whisper Turbo на CUDA 12.8):**
   - Флагманская модель распознавания речи **Whisper Turbo** с аппаратным ускорением **CUDA float16**.
   - Активация голосом по ключевому слову **«Джарвис»** (openWakeWord) или по физической клавише **Copilot**.
   - **Audio Ducking:** автоматическое приглушение фонового системного звука (музыки/игр) до 20% во время записи голоса.

4. **Аппаратная клавиша Copilot (`Shift + Win + F23`):**
   - **Одиночный клик (Tap-to-Talk):** Мягкий звуковой сигнал активации, появление полупрозрачного оверлея-индикатора и запись команды.
   - **Удержание (Hold от 0.4 сек):** Всплывающее окно **Spotlight** по центру экрана с историей запросов и быстрым вводом текста.
   - **Анти-конфликт Windows:** Автоматическое маскирование клавиши Windows для предотвращения случайного открытия меню «Пуск» или системного поиска.

5. **Изоляция и экономия ресурсов под игры:**
   - Перед запуском тяжелых 3D-игр ассистент можно приостановить в трее — память GPU полностью освобождается до 0 МБ.
   - В рабочем режиме суммарная нагрузка ассистента на VRAM составляет всего **~4.5–5.0 ГБ из 8 ГБ**, оставляя свободный запас для Windows DWM и браузера.

## Структура проекта

```text
localAgent/
├── config/
│   ├── settings.json           # Конфигурация (микрофон, язык, триггер-слово, TTS)
│   └── commands.json           # Системные алиасы и сопоставление программ
├── core/
│   ├── audio_listener.py       # Непрерывный аудиопоток, VAD, VU-метр, Wake Word
│   ├── audio_ducking.py        # Управление системной громкостью Windows (PyCAW)
│   ├── speech_to_text.py       # Faster-Whisper Turbo (CUDA 12.8) с выгрузкой VRAM
│   ├── screen_tools.py         # Win32 GDI захват экрана (4 мс), DPI Aware, эмуляция мыши/клавиатуры
│   ├── vision_agent.py         # Ядро Vision Computer-Use (Jedi-3B / Qwen2.5-VL)
│   ├── decision_engine.py      # Двухуровневый маршрутизатор (Fast Path vs Vision Path)
│   ├── app_controller.py       # Управление окнами Windows (WinSta0/Default, запуск, фокус, сворачивание)
│   ├── keyboard_hook.py        # Низкоуровневый перехватчик клавиши Copilot (F23)
│   ├── text_to_speech.py       # Голосовой синтез ответов (TTS)
│   └── executor.py             # Системный исполнитель Win32
├── gui/
│   ├── main_window.py          # Панель управления с карточками статуса и логами
│   ├── floating_pill.py        # Плавающий оверлей со статусом распознавания и кликов
│   ├── spotlight_bar.py        # Плавающая строка ввода команд Spotlight (Alt+Space / Hold Copilot)
│   ├── close_dialog.py         # Диалог подтверждения закрытия («Свернуть в трей или выйти»)
│   ├── tray_manager.py         # Иконка системного трея Windows
│   └── styles.py               # Fluent 2 Dark тема оформления
├── sounds/                     # Аудиосигналы (activate.wav, success.wav, error.wav)
├── tests/
│   ├── test_components.py      # 56 модульных тестов системных компонентов
│   ├── test_screen_tools.py    # Модульные тесты захвата экрана и координат
│   ├── test_cuda_stt.py        # Тест Faster-Whisper на CUDA
│   └── full_verification.py    # Сквозной валидационный аудит всех подсистем (100% OK)
├── create_shortcut.py          # Скрипт создания тихого ярлыка на Desktop
├── main.py                     # Главная точка входа приложения
├── pyproject.toml              # Зависимости проекта (uv)
└── GEMINI.md                   # Архитектурное руководство для разработчиков и ИИ
```

## Запуск и использование

### Обычный запуск (для пользователя):
* Двойной клик по ярлыку на рабочем столе: **`Antigravity Voice.lnk`** (тихий запуск через `pythonw.exe` без консольного окна).
* Либо через PowerShell:
  ```powershell
  Set-Location "C:\Users\denis\Documents\antigravity\localAgent"
  .\.venv\Scripts\python.exe main.py
  ```

### Запуск в свернутом виде (в трей):
```powershell
.\.venv\Scripts\pythonw.exe main.py --minimized
```

### Запуск тестов:
```powershell
# 1. Модульные тесты (56 тестов)
.\.venv\Scripts\python.exe -m unittest tests/test_components.py

# 2. Тесты модуля управления экраном
.\.venv\Scripts\python.exe -m unittest tests/test_screen_tools.py

# 3. Полный валидационный аудит системы
.\.venv\Scripts\python.exe tests/full_verification.py
```
