# Antigravity Voice & Vision Assistant (Jarvis)

Автономный локальный голосовой ассистент и мультимодальный **Vision Computer-Use агент** для Windows 11 с нативной поддержкой аппаратной клавиши **Copilot** (`Shift + Win + F23`), распознаванием речи **Whisper Turbo** и аппаратным ускорением на **NVIDIA GeForce RTX 5050 Laptop GPU (8 ГБ GDDR7)**.

---

## Ключевые возможности

1. **Автономный Vision Computer-Use Агент (Зрение и Действия):**
   - **Универсальное зрительное восприятие:** Ассистенту не требуются захардкоженные селекторы или API под каждый сайт. Модель видит рабочий стол Windows через мгновенный захват Win32 GDI BitBlt (~4 мс), находит элементы и взаимодействует с любыми приложениями и веб-сайтами как живой оператор.
   - **Специализированная VLM (`xlangai/Jedi-3B-1080p`):** Запускается в 4-битном квантовании BitsAndBytes NF4, занимая всего **~3.2 ГБ VRAM**. Обладает субпиксельной точностью кликов по мелким элементам интерфейса и 100% поддержкой русского языка (OCR и рассуждения).
   - **Отказоустойчивый Fallback:** При недоступности основной модели воркер автоматически переключается на `Qwen/Qwen2.5-VL-3B-Instruct`.
   - **Изолированный Worker Process:** Запуск нейросети в отдельном фоновом процессе Windows (`multiprocessing.Process`) полностью исключает конфликт CUDA DLL (`cudnn_cnn64_9.dll`) между CTranslate2 и PyTorch, а также гарантирует освобождение **100% VRAM до 0 МБ** при остановке перед 3D-играми.
   - **Режим Always-Warm:** Модель загружается в память при старте ассистента, обеспечивая мгновенную реакцию без 10-секундной задержки первого запуска.
   - **Глубина автономности (до 8 шагов):** Цикл Sense-Act-Verify с лимитом в 8 шагов обеспечивает выполнение сложных сценариев (поиск роликов на YouTube, подбор товаров на Авито/Ozon, навигация в IDE).

2. **Адаптация под окружение пользователя:**
   - **Динамический мультимониторный захват:** Автоматическое определение монитора, на котором находится курсор мыши или окно Google Chrome (`MonitorFromWindow` / `MonitorFromPoint`). Координаты денормализуются с учетом физических смещений (например, основной экран `1920x1200` и дополнительный `1280x1024` со смещением `-1280`).
   - **Автофокус Google Chrome:** При распознавании веб-задач окно браузера за 0 мс выводится на передний план до захвата экрана.
   - **Гибридный ввод текста:** Короткие команды (<=20 символов) печатаются посимвольно через `SendInput` с флагом `KEYEVENTF_UNICODE`, а длинные запросы (>20 символов) вставляются мгновенно через буфер обмена (`Ctrl+V`) с автоматическим сохранением и восстановлением пользовательских данных.
   - **Детекция изменений экрана и умный повтор:** Сравнение кадров до и после действия. Если экран не изменился (<1.5% пикселей), модель получает сигнал о перекрытии элемента рекламой, поп-апом или баннером cookie для корректировки клика.
   - **Аварийный Fail-Safe:** Мгновенное прерывание любых действий агента при нажатии клавиши `ESC` или физическом движении мыши пользователем (>40 px).

3. **Двухуровневый гибридный маршрутизатор (Fast Path + Vision Path):**
   - **Fast-Path (0 мс, 0 МБ VRAM):** Системные команды (регулировка громкости в %, приглушение звука, сворачивание всех окон `Win+D`, блокировка/выключение ПК, открытие вкладок, прямой переход в разделы «сообщения вк», «подписки на ютубе») отрабатывают мгновенно через Win32 API.
   - **Vision-Path:** Сложные поисковые и интерфейсные запросы передаются автономному Vision-агенту.

4. **Голосовой контур (Faster-Whisper Turbo на CUDA 12.8):**
   - Модель распознавания речи **Whisper Turbo** с аппаратным ускорением **CUDA float16** через `ctranslate2`.
   - Активация голосом по ключевому слову **«Джарвис»** (openWakeWord) или по физической клавише **Copilot**.
   - **Audio Ducking:** автоматическое приглушение фонового звука Windows до 20% во время записи речи.

5. **Аппаратная клавиша Copilot (`Shift + Win + F23`):**
   - **Клик (Tap-to-Talk):** Мягкий звуковой сигнал активации, появление плашки оверлея и мгновенная запись команды.
   - **Удержание (Hold от 0.4 сек):** Всплывающая поисковая строка **Spotlight** по центру экрана.
   - **Анти-конфликт Windows:** Маскирование клавиши Windows (#MenuMaskKey 0xFF) исключает ложное открытие меню «Пуск».

6. **Визуальная индикация:**
   - **Плавающая плашка (`FloatingPill`):** Индикация текущего шага агента `[1/8] Анализирую экран...`, `[2/8] Клик по поисковой строке...`.
   - **Маркер клика (`ClickIndicatorOverlay`):** Полупрозрачный неоновый пульсирующий кружок (350 мс), наглядно подсвечивающий точку клика без перехвата фокуса.

## Структура проекта

```text
localAgent/
├── config/
│   ├── settings.json              # Конфигурация (микрофон, язык, триггер, лимит шагов vision_max_steps: 8)
│   └── commands.json              # Системные алиасы и сопоставление программ
├── core/
│   ├── audio_listener.py          # Непрерывный аудиопоток, VAD, VU-метр, Wake Word
│   ├── audio_ducking.py           # Управление системной громкостью Windows (PyCAW)
│   ├── speech_to_text.py          # Faster-Whisper Turbo (CUDA 12.8)
│   ├── screen_tools.py            # Win32 GDI захват (4 мс), мультимониторность, гибридный ввод, DPI
│   ├── vision_agent.py            # Ядро Computer-Use (Jedi-3B, Fail-Safe, очереди IPC, фоновый воркер)
│   ├── decision_engine.py         # Двухуровневый маршрутизатор (Fast Path vs Vision Path)
│   ├── app_controller.py          # Управление окнами Windows (запуск, фокус, сворачивание)
│   ├── keyboard_hook.py           # Низкоуровневый перехватчик клавиши Copilot (F23 / 0x8E)
│   ├── text_to_speech.py          # Синтез голосовых ответов (TTS)
│   └── executor.py                # Системный исполнитель Win32 и интеграция с Vision-агентом
├── gui/
│   ├── main_window.py             # Панель управления с карточками статуса и логами
│   ├── floating_pill.py           # Плавающий статус-оверлей и ClickIndicatorOverlay
│   ├── spotlight_bar.py           # Плавающая строка ввода команд Spotlight (Hold Copilot)
│   ├── close_dialog.py            # Диалог выхода («Свернуть в трей или выйти»)
│   ├── tray_manager.py            # Иконка системного трея Windows
│   └── styles.py                  # Fluent 2 Dark тема оформления
├── sounds/                        # Звуковые сигналы (activate.wav, success.wav, error.wav)
├── tests/
│   ├── test_components.py         # Модульные тесты роутера, экзекутора и системных вызовов
│   ├── test_screen_tools.py       # Тесты координатной сетки, мультимониторности и захвата
│   ├── test_vision_agent.py       # Тесты ActionParser, Fail-Safe монитора и менеджера процессов
│   ├── test_cuda_stt.py           # Тест Faster-Whisper на CUDA
│   └── full_verification.py       # Сквозной аудит всех 9 подсистем (100% OK)
├── create_shortcut.py             # Скрипт создания тихого ярлыка на Desktop
├── download_vision_model.py       # Фоновая загрузка весов Jedi-3B в кэш Hugging Face Hub
├── main.py                        # Главный координатор приложения (PyQt6)
├── pyproject.toml                 # Окружение uv
├── README.md                      # Руководство пользователя (этот файл)
└── GEMINI.md                      # Архитектурное руководство для разработчиков
```

## Запуск и использование

### 1. Обычный запуск (для пользователя):
* Двойной клик по ярлыку на рабочем столе: **`Antigravity Voice.lnk`** (тихий запуск через `pythonw.exe`).
* Либо через PowerShell:
  ```powershell
  Set-Location "C:\Users\denis\Documents\antigravity\localAgent"
  .\.venv\Scripts\python.exe main.py
  ```

### 2. Фоновое скачивание весов модели Vision-агента:
```powershell
.\.venv\Scripts\python.exe download_vision_model.py
```

### 3. Запуск тестов:
```powershell
# Полный сьют unit-тестов (75 тестов, 100% PASS)
.\.venv\Scripts\python.exe -m unittest discover tests

# Комплексный аудит всех 9 подсистем (CUDA, Звук, STT, GUI, Copilot Hook, Vision-агент)
.\.venv\Scripts\python.exe tests/full_verification.py
```
