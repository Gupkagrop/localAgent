# Архитектура графического интерфейса (Frontend)

Интерфейс построен на базе **PyQt6** с использованием нативного стилизованного оформления **Windows 11 Fluent Dark** и немодальных плавающих оверлеев.

---

## 1. Компонентная структура UI

```text
gui/
├── main_window.py      # Главная панель управления (Dashboard)
├── floating_pill.py    # Плавающий статус-оверлей и маркер кликов High DPI
├── spotlight_bar.py    # Всплывающая строка быстрого поиска и ввода команд
├── tray_manager.py     # Интеграция с системным треем Windows и управление VRAM
├── screen_glow.py      # Контурная неоновая подсветка экрана HUD
├── close_dialog.py     # Диалог подтверждения сворачивания/выхода
└── styles.py           # Таблицы стилей QSS и константы цветовой палитры Fluent 2
```

---

## 2. Ключевые компоненты

### 1. Панель управления ([`MainWindow`](file:///c:/Users/denis/Documents/antigravity/localAgent/gui/main_window.py))
- Отображает карточки статусов оборудования (микрофон, хук Copilot, статус VRAM).
- Содержит выпадающий список доступных в системе синтезаторов речи SAPI5 с регулятором скорости и кнопкой тестового воспроизведения.
- Предоставляет консоль живых логов (включая логи изолированного воркера) и симулятор отправки текстовых команд.
- Кнопка «⚡ Проверить все системы» запускает фоновый процесс комплексной диагностики без зависания UI.

### 2. Плавающий оверлей ([`FloatingPill`](file:///c:/Users/denis/Documents/antigravity/localAgent/gui/floating_pill.py))
- Флаги окна: `Qt.WindowType.WindowStaysOnTopHint | Qt.WindowType.FramelessWindowHint | Qt.WindowType.Tool`.
- Поддерживает прозрачность фона (`WA_TranslucentBackground`).
- Динамически отображает шаги работы Computer-Use: `[1/8] Анализирую экран...`.
- Содержит анимированный синий светодиод (VU-метр), пульсирующий в такт громкости речи пользователя на основе RMS-энергии.

### 3. Маркер клика ([`ClickIndicatorOverlay`](file:///c:/Users/denis/Documents/antigravity/localAgent/gui/floating_pill.py))
- Полупрозрачный полноэкранный оверлей, не перехватывающий клики мыши (`WA_TransparentForMouseEvents`).
- Рисует неоновый пульсирующий круг в физических экранных координатах клика модели на 350 мс.
- Учитывает коэффициент масштабирования Windows High DPI (`devicePixelRatio()`), гарантируя точное позиционирование на экранах 125%, 150%, 200%.

### 4. Строка ввода ([`SpotlightBar`](file:///c:/Users/denis/Documents/antigravity/localAgent/gui/spotlight_bar.py))
- Вызывается глобальным сочетанием `Alt+Space` или удержанием физической клавиши Copilot (>500 мс).
- Поддерживает динамическое автодополнение команд (Live Auto-Suggestions) из [`commands.json`](file:///c:/Users/denis/Documents/antigravity/localAgent/config/commands.json).

### 5. Контурная подсветка экрана ([`ScreenGlowOverlay`](file:///c:/Users/denis/Documents/antigravity/localAgent/gui/screen_glow.py))
- Немодальный полноэкранный полупрозрачный оверлей, визуализирующий статус активности ассистента.
- Отображает мягкое неоновое свечение по периметру экрана (HUD border glow) во время работы агента Computer-Use или распознавания.
- Игнорирует события мыши (`WA_TransparentForMouseEvents`) и не блокирует взаимодействие с рабочим столом.

### 6. Менеджер системного трея ([`TrayManager`](file:///c:/Users/denis/Documents/antigravity/localAgent/gui/tray_manager.py))
- 4 динамических состояния иконки:
  * `idle` — ассистент готов к работе (зеленый индикатор `#22C55E`).
  * `listening` — идет запись или распознавание голоса (пульсирующий красный `#EF4444` / `#F87171`).
  * `working` — выполняется шаг Computer-Use или Fast-Path (пульсирующий фиолетово-голубой `#A855F7` / `#38BDF8`).
  * `stopped` — ассистент временно остановлен пользователем (серый `#6B7280`).
- Пункт меню «Остановить ассистента» мгновенно отправляет сигнал завершения воркеру зрения и выгружает Faster-Whisper, **полностью освобождая VRAM до 0 МБ** перед запуском 3D-игр.
