# Архитектура Computer-Use и Vision Agent

Подсистема автономного взаимодействия с интерфейсом Windows 11 функционирует в отдельном операционном процессе для предотвращения конфликтов библиотек глубокого обучения и защиты от переполнения видеопамяти.

---

## 2. Скоростной захват экрана (Win32 GDI BitBlt)

Модуль [`core/screen_tools.py`](file:///c:/Users/denis/Documents/antigravity/localAgent/core/screen_tools.py) реализует прямой низкоуровневый захват экрана через Windows GDI API:
- Задержка захвата кадра составляет всего **~4 мс** (в 10 раз быстрее стандартных Python-библиотек).
- Корректная работа в сессии рабочего стола `WinSta0\Default`.
- Автоматическая мультимониторность: детекция монитора под курсором или активным окном приложения (`MonitorFromPoint` / `MonitorFromWindow`).
- Нормализация координат [0..1000] модели Jedi-3B в физические пиксели экрана с учетом смещений `left`, `top` и масштабирования High DPI.

## 3. Парсер действий (ActionParser)

Модель Jedi-3B генерирует JSON-команды в формате CoT (Chain-of-Thought) + Action:
```json
{
  "thought": "Нажимаю на адресную строку браузера для ввода запроса",
  "action": "click",
  "coord": [500, 80]
}
```

Модуль нормализует алиасы действий:
- `left_click` / `click` -> `click` (клик ЛКМ по нормализованным координатам).
- `write` / `input` -> `type` (гибридный ввод: `SendInput` Unicode для коротких строк $\le 20$ символов, `Ctrl+V` через буфер обмена для строк $> 20$ символов с сохранением пользовательского содержимого буфера).
- `done` / `finished` -> `finish` (успешное завершение цепочки шагов).
- `scroll` -> вертикальная или горизонтальная прокрутка колеса мыши.

## 4. Детекция изменений экрана и поп-апов

Перед каждым действием агент вычисляет разницу пикселей текущего и предыдущего кадров:
- Если изменение составляет **менее 1.5%**, система определяет, что клик мог быть заблокирован рекламой, всплывающим окном или баннером согласия на cookie.
- Модели передается дополнительная контекстная подсказка в системный промпт: *"Экран не изменился после предыдущего действия. Возможно, требуется закрыть поп-ап или кликнуть в другое место"*.

---

## 5. Защитный контур Fail-Safe

Безопасность пользователя обеспечивается аппаратным перехватом:
1. **Нажатие клавиши ESC (`0x1B`):** Немедленная остановка цикла агента.
2. **Физическое движение мыши пользователем (>40 px):** Если пользователь перехватывает управление физической мышью, агент мгновенно прерывает выполнение задачи и возвращает управление человеку.
