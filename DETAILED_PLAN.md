## 3. Что было исправлено в ходе разработки (Issue Post-Mortem)

| Проблема | Причина | Примененное решение | Статус |
| :--- | :--- | :--- | :---: |
| Открытие поиска Windows при нажатии Copilot | В Windows 11 Build 26200 при выключенном Copilot Shell перенаправляет кнопку на Search, а старый код 0xFF игнорировался | Реализовано маскирование через `VK_CONTROL` (`0x11`) при каждом нажатии `VK_F23` | **Устранено** |
| Неверный код клавиши Copilot в коде | Windows SDK и клавиатуры ASUS используют `VK_F23 = 0x86` (134), тогда как в коде стоял `0x8E` | Добавлена поддержка обоих кодов (`0x86` и `0x8E`), а также резервный шорткат `Ctrl+Shift+J` | **Устранено** |
| Зависание хука клавиши Copilot | 64-битный адрес модуля усекался в ctypes до 32-битного int, вызывая ошибку 126 | Хук переведен на библиотеку `pynput` со встроенным Win32 event filter | **Устранено** |
| Зависание теста микрофона на распознавании | CTranslate2 не находил `cublas64_12.dll` из-за отсутствия пакета nvidia-cublas | Установлены пакеты `nvidia-cublas-cu12`, DLL скопированы в `ctranslate2/` | **Устранено** |
| Конфликт двух потоков микрофона | Два параллельных потока открывали `sd.InputStream` на одном устройстве WASAPI | Переход на архитектуру Single Persistent Stream в `AudioListener` | **Устранено** |
| Отсутствие отклика на слово «Джарвис» | Завышенный порог энергии речи (0.010) и сброс устройства ввода при старте | Снижен порог энергии до 0.004, сохраненный микрофон передается в поток при старте | **Устранено** |
| Не вызывалась локальная LLM для неизвестных команд | В DecisionEngine не был реализован вызов нейросети Qwen2.5 при отсутствии regex-совпадений | Реализован метод `_parse_with_llm()` с семантическим роутингом и диалоговым `general_answer` | **Устранено** |
| Отсутствие подтверждения опасных команд | Команды выключения/перезагрузки не выводили диалог подтверждения | Добавлен `confirm_action_signal` с всплывающим окном `QMessageBox.warning` | **Устранено** |
| Обрезание нижних кнопок в окне настроек | Фиксированная высота окна при масштабировании экрана Windows 125%/150% | Внедрение `QScrollArea` с поддержкой адаптивного скроллинга во всех вкладках | **Устранено** |
